## Domaines

### Data Science & Machine Learning

- Analyse exploratoire et visualisation de données
- Nettoyage et préparation des données
- Feature engineering
- Classification et régression
- Gestion des classes déséquilibrées
- Détection d'anomalies
- Évaluation et validation des modèles
- Scikit-learn, Pandas, NumPy, Matplotlib, Seaborn

### Data Engineering

- Conception de pipelines ETL / ELT
- Ingestion et transformation de données
- Orchestration de workflows avec Airflow
- Intégration et flux de données avec Apache NiFi
- Streaming avec Kafka
- Traitement distribué avec Spark
- SQL et bases de données
- PostgreSQL, MongoDB
- Docker / Docker Compose
- Data quality
- Metabase

### AI, NLP & Computer Vision

- Fine-tuning de modèles Transformers
- NLLB-200, MMS et PEFT / LoRA
- Traduction automatique et reconnaissance vocale
- NLP pour les langues africaines, notamment l'éwé
- Hugging Face
- Computer Vision
- YOLOv8 et OpenCV
- Bases du Deep Learning avec NumPy

### Software Engineering

- Python, FastAPI, Streamlit
- Java, Spring Boot
- PHP, Laravel
- Node.js
- Flutter
- REST APIs
- Git & Docker
