# Romaric Nadjire

Étudiant en **M1 Intelligence Artificielle** à l'École Polytechnique de Lomé (Togo), orienté **Data Science, Machine Learning et Data Engineering**, avec une expérience préalable en développement logiciel full-stack.

Je m'intéresse particulièrement au traitement des données réelles (nettoyage, qualité, pipelines) et aux applications de l'IA aux **langues africaines peu dotées**, notamment l'éwé.

## Domaines

**Data Science / Machine Learning**
Analyse exploratoire, feature engineering, classification (régression logistique, Random Forest), gestion des classes déséquilibrées, évaluation (précision / rappel, F1, ROC, validation croisée), visualisation.

**Data Engineering**
ETL / ELT (Talend), streaming (Kafka), traitement distribué (Spark), PostgreSQL, MongoDB, Docker / Docker Compose, qualité des données, tableaux de bord (Metabase).

**AI / NLP / Computer Vision**
Fine-tuning de modèles Transformers (NLLB-200 + LoRA, MMS) pour la traduction et la reconnaissance vocale en éwé, modèles publiés sur Hugging Face ; détection d'objets et de visages (YOLOv8, OpenCV) ; bases du deep learning implémentées en NumPy.

**Software Engineering**
Python (FastAPI, Streamlit), Java (Spring Boot), PHP (Laravel), Node.js, Flutter, REST API, bases de données relationnelles, Git, Docker.
